ИНСТРУКЦИЯ ДЛЯ ИИ-ПОМОЩНИКА №2 — С ЧЕГО НАЧАТЬ
================================================

Ты подключён к репозиторию учебного тренажёра по Python. Твоя задача — написать
уроки этапа «Мостик» (8 файлов JSON) в папке content/bridge/. Движок, интерфейс
и уроки этапа «Основы» делает другой ИИ в другой ветке — их не трогай.

ШАГ 1. Прочитай полностью:   docs/TZ_CONTENT_BRIDGE.md
       Это техническое задание: формат данных, список уроков, требования к
       тестам, инструмент проверки, порядок сдачи. Всё, что нужно, — там.

ШАГ 2. Посмотри эталонный урок:   content/basics/01_variables.json
       Твои файлы должны быть в точно таком же формате.

ШАГ 3. Проверь, что окружение работает (нужен Python 3.10+, ничего ставить не надо):
           python3 tools/validate_lessons.py
       Ожидаемый ответ: «РЕЗУЛЬТАТ: OK».

ШАГ 4. Создай свою ветку от main (например content/bridge-lessons) и пиши уроки
       по одному, в порядке из таблицы в разделе 3 ТЗ. После каждого урока:
           python3 tools/validate_lessons.py content/bridge/*.json
       Урок готов только при «Ошибок: 0».

ШАГ 5. Впиши уроки в content/index.json (этап "bridge"), прогони
           python3 tools/validate_lessons.py --strict
       и открой pull request в main. Что написать в описании PR — раздел 7 ТЗ.

ГРАНИЦЫ:
  - Меняешь только content/bridge/** и список "lessons" этапа bridge в content/index.json.
  - Не меняешь engine/, tools/, content/basics/, PYTHON_PLAN.txt, app/, index.html.
  - Не добавляешь новые поля и типы блоков в формат урока.
  - Не используешь starter_code (редактор ученика должен быть пуст).
  - Только стандартная библиотека Python в задачах и примерах.

Если что-то в ТЗ противоречит реальному поведению валидатора — прав валидатор;
опиши расхождение в PR.

КАРТА РЕПОЗИТОРИЯ (что где):
  PYTHON_PLAN.txt              план обучения пользователя (контекст, читать не обязательно)
  docs/TZ_CONTENT_BRIDGE.md    ТВОЁ ТЗ
  content/index.json           реестр уроков по этапам
  content/basics/              уроки этапа 1 (делает ИИ №1) — эталон формата
  content/bridge/              ТВОИ уроки
  engine/py/harness.py         исполняет код ученика и сверяет с тестами (общий для приложения и валидатора)
  tools/validate_lessons.py    проверка уроков — твой главный инструмент
