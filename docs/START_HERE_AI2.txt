ИНСТРУКЦИЯ ДЛЯ ИИ-ПОМОЩНИКА — С ЧЕГО НАЧАТЬ
============================================

Репозиторий тренажёра по Python: уроки-данные (content/), движок проверки
(engine/py/harness.py), веб-приложение (index.html + app/, сборка tools/build_site.py)
и учебный план пользователя (PYTHON_PLAN.txt). Деление работы между несколькими ИИ
осталось в прошлом — этапы «Основы» и «Мостик» смержены в main; всю дальнейшую
работу (контент и приложение) ведёт этот помощник.

ШАГ 1. Формат урока и все правила — docs/TZ_CONTENT_BRIDGE.md (разделы 0–6).
       Эталон формата: content/basics/01_variables.json.
ШАГ 2. Проверь окружение (Python 3.10+, ставить ничего не надо):
           python3 tools/validate_lessons.py --strict
       Ожидаемый ответ: «РЕЗУЛЬТАТ: OK».
ШАГ 3. Правь контент/приложение, после изменений пересобирай данные приложения:
           python3 tools/build_site.py
       Он генерирует app/data.js, pypath.html (всё приложение одним файлом) и
       сам вписывает версии ассетов ?v=хэш в index.html — кэш браузера не залипает.
       Логику гейтинга тем проверяй без браузера: node tools/test_core.mjs
       (все проверки должны быть PASS).
ШАГ 4. Коммить по одному логичному куску, пушь в свою ветку, открывай PR в main.
       Мержит только пользователь.

ГРАНИЦЫ:
  - Не меняй поля и типы блоков формата урока без острой нужды.
  - starter_code не использовать: редактор ученика пуст.
  - В задачах и примерах — только стандартная библиотека Python.
  - Ответы программ детерминированы: random — только через seed, datetime.now()
    в задачах запрещён; всё проверяй реальным прогоном, не на глаз.
  - Проза уроков — на «ты», без выдуманных фактов; реальные числа в примерах
    сверяй прогоном кода.
  - PYTHON_PLAN.txt — правишь только по его разделу 10 (историю не удалять,
    добавления с датой; чужие чекбоксы не трогай).
  - engine/py/harness.py и tools/validate_lessons.py — только при реальном баге,
    с описанием в PR.

Если что-то в ТЗ противоречит реальному поведению валидатора — прав валидатор;
опиши расхождение в PR.

КАРТА РЕПОЗИТОРИЯ (что где):
  PYTHON_PLAN.txt              план обучения пользователя (править по разделу 10)
  docs/TZ_CONTENT_BRIDGE.md    формат урока и правила контента (действуют для всех этапов)
  content/index.json           реестр уроков по этапам
  content/basics/              уроки этапа 1 «Основы»
  content/bridge/              уроки этапа «Мостик» (01–08, приняты)
  index.html + app/            веб-приложение (чистый JS, без сборки; index.html
                               требует соседние файлы app/, pypath.html — самодостаточная
                               однофайловая версия той же программы)
  pypath.html                  генерируемый одиночный файл-сборка (не редактировать руками)
  engine/py/harness.py         исполняет код ученика и сверяет с тестами
                               (один файл для приложения и валидатора)
  tools/build_site.py          сборка data.js + pypath.html + версии ассетов
  tools/validate_lessons.py    проверка уроков — главный инструмент
  tools/test_core.mjs          проверка логики разблокировки тем (node, без браузера)
